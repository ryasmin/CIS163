## Level: Easy-Moderate

#### Exercise 1: Sum of list using index
Write a recursive function that returns the sum of all elements in a list without using slicing. Use a helper function to keep track of the current index.

#### Exercise 2: First uppercase index
Write a recursive function that returns the index of the first uppercase letter in a string. Use a helper function to track the current index.

#### Exercise 3: Location of Specific Value
Write a recursive function that takes a list (`lst`) and a given value `x` and returns a list with the indecies of where the given value appears in the list. 
Use a helper function to track the current index.
```
get_index(lst = [1, 0, 0, 1, 3, 0]) -> [1, 2, 5]
```

#### Exercise 4: Location of Even Values
Write a recursive function that takes a list (`lst`) and returns a list with the indecies of where the elements in the list are even. 
Use a helper function to track the current index.
```
get_index(lst = [1, 0, 0, 1, 3, 0]) -> [1, 2, 5]
```

#### Exercise 4: Find maximum element
Write a recursive function that returns the maximum element in a list using a helper function. The helper should keep track of the current maximum.
